```javascript title="TypeScript"
const params = new URLSearchParams({ carrierCode: "JJ", flightNumber: "202" });

const res = await fetch(
  `https://fef3af9d-2af6-417d-9153-30ea3eb9ad46.mock.pstmn.io/flight-status?${params}`,
  { headers: { "x-api-key": process.env.JJ_API_KEY, Accept: "application/json" } }
);

const flight = await res.json();
console.log(`${flight.carrierCode}${flight.flightNumber} is ${flight.status}`);
```

## Error handling

Errors are machine-first: a stable `code` you can branch on, plus a human-readable `message` you can log.

<AccordionGroup>

<Accordion title="400 · INVALID_FLIGHT_NUMBER">

Triggered when `flightNumber` contains anything other than digits. Validate against `^[0-9]{1,4}$` before you call.

```json title="400 Bad Request"
{
  "code": "INVALID_FLIGHT_NUMBER",
  "message": "Flight number must consist of numbers only. Expected pattern: ^[0-9]{1,4}$"
}
```

</Accordion>

<Accordion title="404 · FLIGHT_NOT_FOUND">

The carrier and flight number are well-formed, but no flight matches. Treat as an empty result, not a failure — flight numbers retire and rotate.

```json title="404 Not Found"
{
  "code": "FLIGHT_NOT_FOUND",
  "message": "No flight found for carrier JJ, flight number 404."
}
```

</Accordion>
